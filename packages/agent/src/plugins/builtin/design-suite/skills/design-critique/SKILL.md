# Design critique

Assess the stated user goal before judging the interface. Separate observations
from recommendations. Rank findings by user impact and confidence, then give a
smallest-first improvement sequence. Do not invent visual details that are not
in the provided image, Figma context, or implementation.

Use `design_audit` when a repeatable checklist would help. If Figma is
connected, request only the file or node context needed for the review.
