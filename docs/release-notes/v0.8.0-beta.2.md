**v0.8.0-beta.2** (2026-09-12) — pre-release on the `0.x` line.

Browser session sharing, memory footprint reclamation, code review
workspace, and a second Electron runtime jump (36 → 44). Published as a
beta because the packaged build has not yet been smoke-tested on the new
runtime.

**Highlights**

- **Browser & extension**
  - Share one Chromium across Playwright browser sessions instead of
    spawning one per session.
  - Extension: group agent tabs per session instead of a dedicated window;
    tab group management (plan 524).
  - Reclaim webview memory on close with a budget watchdog (plan 521).

- **Electron runtime**
  - Electron 36 → 44. `npm ci` no longer source-compiles a stale
    better-sqlite3 11.10.0 copy; the lockfile dedupes all workspaces onto
    the 13.0.3 tarball-prebuilt release.

- **Agent & compaction**
  - Turn + token cooldown gate and over-threshold loop brake (plan 517).
  - Per-step compaction progress UI (plan 517 P3); compaction context
    window aligned with the context ring and attached to worker init.
  - Rebase events routed through `journal:emit` with rotation trigger
    wired; archive rotation origin renumbered.

- **Code review workspace**
  - Port Codex review panel patterns into the code review workspace
    (scope dropdown, split-diff expanded mode, commit popover).

- **CLI & gateway**
  - Plan 520 executed: gateway slimmed to router + status broadcast,
    gateway session resolution + allow-list enforced main-side, pairing
    control plane removed from the CLI.

- **Computer use**
  - Plan 519 harness landed with live-use fixes; coordinate conversion for
    DPI-scaled displays and action overlay indicator.

- **Tools**
  - Replace the 241 tools-array merge with a tail schema block
    (plan 480 P3.2).

- **UI / UX**
  - Permission prompt redesigned to match composer panels.
  - Sidebar terminal rendering upgrade; new-thread dropdown removed.
  - Long unbreakable tokens wrap in the user message bubble; transparent
    hover actions on thread items and bot contacts.
  - Renderer memory: free retained chat-stream state to bound renderer
    memory growth.

- **Chores**
  - Dead-code sweep across `src`, `electron`, and `packages`; unused
    `undici` / `streamdown` dependencies dropped; tracked build artifacts
    removed.

**Pre-release verification**

- Packaged smoke test on Electron 44 — pending (the reason this is a
  beta).
