**v0.8.0-beta.3-macos12** (2026-09-12) — macOS 12 compatibility build on the
`feat/electron43-macos12` branch.

Identical to v0.8.0-beta.2 except the runtime is downgraded from Electron 44
to **Electron 43.7.0**, the last line that still runs on macOS 12 (Monterey).
Electron 44's Chromium dropped Monterey, so the beta.2 artifacts require
macOS 13+; this branch exists to keep macOS 12 machines supported.

- Electron 44.2.0 → 43.7.0 (macOS minimum drops back to 12).
- better-sqlite3 13.0.3 kept — its tarball prebuilds are runtime-agnostic
  and verified loading under the Electron 43 ABI.
- Everything else matches v0.8.0-beta.2.
