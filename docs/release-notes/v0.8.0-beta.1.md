**v0.8.0-beta.1** (2026-09-10) — pre-release on the `0.x` line.

Bot platform landing, channels & connectors, gateway route rework, and a
major Electron runtime jump. Ports the Grok Bot mechanism (wake bus, run
scheduler, DM/rooms, tool-approval cards), unifies app connectors behind a
registry, moves channel delivery onto the gateway, and upgrades Electron
28 → 36. Published as a beta because the packaged build has not yet been
smoke-tested on the new runtime.

**Highlights**

- **Bot platform (Grok Bot port)**
  - Agent wake bus: three lanes, wake-source registry, `pending_wakes`
    persistence + rearm, preemption/redrive (plan 476).
  - Bot run scheduler: busy-time queuing, source-graded lanes, lock-origin
    attribution, user preemption/supersede, watchdog, group-member turns
    (plan 500).
  - Bot-bound routines and polling event listeners wired through the wake
    bus (plan 499 / 476 P2.3).
  - Durable tool-approval cards with pause + resume and a one-shot ledger
    (plan 498); bot-direct ask/permission cards in the chat flow (plan 494).
  - Multi-bot chat UI, unified create entry, quick-create via sidebar plus,
    per-bot reasoning level, avatar emoji (plan 483).
  - Shared rooms: `groups.toml`, room turn dispatcher, `PostToRoomTool`,
    one-click room creation, group chat view (plan 478).
  - Bot-scoped skills under each bot's own directory; frozen bot prompts
    and DM routing rework.

- **Channels & connectors**
  - Channel attachments both ways: inbound media lands in
    `agents/<id>/attachments/` with path injection, outbound real upload
    with `MediaReply` mapping (plan 507).
  - Per-bot feishu / weixin / telegram channel bindings and outbound
    delivery; Telegram sends over HTTPS and fails fast.
  - Connector catalog RPC + `list_app_connectors` / `connect_app` tools with
    in-conversation connection cards (plan 503); unified `AppConnector`
    class + `AppConnectorRegistry` (plan 455).
  - QQ Mail (IMAP/SMTP), Gmail, Calendar and Microsoft 365 app connectors;
    codex-aligned approval parity (plan 449).
  - `twitter_post` browser action for publishing tweets.

- **Gateway**
  - Auto-start the gateway on packaged boot when `channels.auto_start` is on.
  - Channel-only gateway RFC documented; stream / delivery / permission
    helpers collapsed into local helpers.

- **Sessions & rollout data**
  - Session tool: spawn real child project sessions with lineage, async run
    and parent wake-on-complete, plus list/get/reply/cancel/rename (plan 504).
  - Rollout as first-class data: single-file export/import with resume,
    explicit index reconcile, `session:forkAt` checkpoint forks, and archive
    rotation for non-bot sessions (plan 506).
  - Message thread / fork branching layer (plan 486).

- **Electron runtime**
  - Electron 28 → 36 with cold-start perf fixes and bundle trimming.
  - Native macOS titlebar; Mica reapplied after window state transitions.
  - Prebuilt `ripgrep` bundled for packaged builds; Tab insert via
    `@nut-tree-fork/nut-js`.

- **Computer use**
  - `computer-use-demo` daemon lifecycle (spawn/restart/heartbeat), Wake
    Agent orb with global hotkey + IPC handlers.

- **Harness & agent internals**
  - Read/Edit freshness protocol: contentSha read-state, ApplyPatch
    re-anchor, WriteTool read-first gate (plan 448).
  - Harness signal contracts: `is_error` propagation and apply_patch
    write-permission (plan 428).
  - Per-event granularity journal with fence sync replacing turn-batched
    persistence (plan 441).
  - Token accounting upgrade + cache-health scanner in the usage summary
    (plan 444).
  - Provider stream coverage: refusal handling, unknown-block downgrade,
    encrypted-reasoning replay (plan 440).
  - Multi-protocol extension: Bedrock Converse / Gemini / Vertex Express
    wire protocols + explicit family wrapper layer (plan 451).

- **UI / UX**
  - Unified `NewChatView` with the welcome layout; `cmd-k` search command
    palette; sidebar rows surface an awaiting-input pill.
  - Time-of-day welcome greeting and project selector below the composer.
  - Chat rendering perf: memoized markdown, off-screen
    `content-visibility`, rAF-batched stream notify.

**Breaking changes**

- `@duya/gateway` no longer exports `StreamHandler`, `DeliveryLedger`,
  `DeliveryMirror`, `PermissionBroker`, `CatchupBatchProcessor`,
  `buildAttachments`, or the display-config helpers. Downstream importers
  must switch to the in-package/local paths.

**Pre-release verification**

- Packaged smoke test on Electron 36 — pending (the reason this is a beta).
- `npm run typecheck:all` — to be confirmed before promoting to stable.
