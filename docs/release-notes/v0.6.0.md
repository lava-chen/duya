**v0.6.0** (2026-08-14) — minor release on the `0.x` line.

Configuration unification, memory curation rewrite, mode engine, and a
context-usage overhaul. Consolidates provider/config storage into a
single TOML store, ships single-shot deterministic memory curation,
adds the mode/goal state-machine engine, and revamps the vision
credential model plus the context usage ring.

**Highlights**

- **Configuration unification**
  - `config.toml` becomes the single source of truth; removes `boot.json`
    and legacy config files. DB/rollout/attachments roots now read from
    `config.toml`.
  - `ConfigStore` + `ConfigStoreReader` replace the old ConfigManager;
    plugin/marketplace sources and provider overrides are config-backed.
  - Cron single-source: `cronjob.toml` with ordinary-session execution.

- **Memory system rewrite**
  - Single-shot deterministic curation (parser + file writer) replaces
    the multi-pass loop; `curation_ledger` claim/complete/fail ledger and
    `curation_runs` migration.
  - `memory_layout.json` section layout, `system_log`, and staged
    `stage1_policy` prompt with canary fixtures.
  - Ad-hoc inputs merged into the curation cycle with max-input truncation;
    `memory_entries` cache rebuilt from file manifests.

- **Mode engine (goal / plan-task / research / conductor)**
  - `ModeTracker` engine, `ModeCoordinator` wiring into the streamChat
    turn loop, and `mode_state_snapshots` store.
  - Goal mode state machine + tools with rich UI state; plan-task session
    toggle persisted across reloads.

- **Tools & agent internals**
  - `allowedRoots` sandbox across Read/Write/Edit/Grep/Glob tools.
  - `ApplyPatchTool` + file-mutation-queue; hardened edit/grep/glob.
  - Projection-compress pipeline for read/bash long bodies and grep/glob
    tables; anti-dead-loop guard and todo gate.

- **Vision credential model (BREAKING)**
  - `auxiliary.vision.apiKey` removed — the vision chain now always derives
    its credential from the configured provider, so vision stays in lockstep
    with the provider that already authenticates the agent.

- **Context usage ring overhaul**
  - `ContextUsagePopover` removed; `ContextUsageRing` rewritten with
    pi-style cumulative totals (↑input / ↓output / R cache / `$cost`).
  - Adds `estimateCost` + `formatTokensPi` and a cache-convention guard so
    fully cache-served requests still count as meaningful usage.

- **Voice, gateway, and misc**
  - Voice CLI control plane; cloud track + model selection UI; auto-inject
    voice-setup guide when STT is not ready.
  - Telegram channel aligned with Hermes UX (streaming hardened, replies
    rendered with hermes markdown, reasoning stripped).
  - AGENTS.md moved to system field with cache_control; skill/slash-command
    and BTW chat panel enhancements.

**Breaking changes**

- `auxiliary.vision.apiKey` is removed; vision credentials are resolved
  from the configured provider.
- `boot.json` and legacy config files are dropped in favor of `config.toml`.
- Legacy `memory_entries` / `memory_evidence` / `phase2_runs` tables dropped
  (migration 0009).
