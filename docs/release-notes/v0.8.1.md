**v0.8.1** (2026-09-14) — patch/minor release on the `0.x` line.

Sidebar new-conversation shortcut, AGENTS.md project-home integration,
project service migration to db/core, and various UI polish fixes.

**Highlights**

- **Sidebar**
  - New conversation button appears above the primary nav (canvas /
    automation / projects), providing a quick shortcut to start a fresh
    session without reaching for the create menu
    (`feat(sidebar): add new conversation button above primary nav`).

- **AGENTS.md project-home (plan 525 phase 7)**
  - Each AGENTS.md is now wrapped with a codex-style mini-header
    showing the project root, and the agent loads the project-home file
    on startup so it has immediate context about the current workspace
    (`feat(agent): wrap each AGELS.md with codex-style mini-header and
    load project-home file`,
    `feat(memory-state): seed project home with AGENTS.md at create
    time`).

- **Project service migration**
  - Project service migrated from memory-state to db/core, consolidating
    the single source of truth for project entities
    (`refactor: migrate project service from memory-state to db/core`).

- **Marketplace & extensions**
  - Marketplace source manager now opens as a modal for cleaner UX
    (`feat(extensions): open marketplace source manager as modal`).

- **UI polish**
  - Project picker menu capped at ~9 visible rows so it no longer
    dominates the welcome composer
    (`fix(ui): cap project picker menu at ~9 visible rows so it stops
    dominating the welcome composer`).
  - DropdownMenu list height capped so long item lists scroll inside
    the popover
    (`fix(ui): cap DropdownMenu list height so long item lists scroll
    inside the popover`).
  - TodoToolRow component added for semantic todo list display
    (`feat(ui): add TodoToolRow component for semantic todo list
    display`).

- **Agent / electron fixes**
  - Token usage and last_call fields persisted; SSE fields plumbed
    through correctly
    (`fix(agent): persist cumulative tokenUsage + last_call, plumb SSE
    fields`).
  - Bundled app icon resolved via `duya-file://` protocol
    (`fix(electron): resolve bundled app icon via duya-file:// protocol`).

**Breaking changes**

None.

**Pre-release verification**

- `npm run typecheck:all` — pre-existing type errors in
  `ExtensionInstallPrompt.tsx`, `BrowserExtensionSection.tsx`, and
  `MessageList.test.tsx` are tracked for follow-up; they do not affect
  runtime. Agent / cli / conductor / voice workspaces typecheck clean.
