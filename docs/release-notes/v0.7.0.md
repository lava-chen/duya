**v0.7.0** (2026-08-20) — minor release on the `0.x` line.

Memory RAG + first-class hooks + agent profile/permission live switching
+ image generation. Land the full hook-system runtime, ship a usable
memory search/scan experience, refactor the usage dashboard, and add an
image-generation tool.

**Highlights**

- **Memory RAG (P0)**
  - `curation_publish_orchestrator.ts` rebuilds the search index from
    the active curation manifest and exposes `POST /v1/memory/{search,
    rebuild}` endpoints.
  - `duya memory doctor/status/setup/enable/disable/set` CLI surface
    with machine-driven provider/model recommendation and embedding
    activation.
  - `memory-search` system-level skill (`.system/memory-search`)
    composes a `UserPromptSubmit` hook + a hybrid BM5 + vector recall
    that injects `### 相关记忆` at the top of the first turn.
  - Frontend Settings adds a RAG card with scan_paths editor,
    embedding provider/model pickers and an "enabled" toggle.

- **Hook system (P0)**
  - Full hook runtime wires PreTurn / PostToolUse / PreFinalize /
    PostTurn events with matcher filtering, async delivery and
    crash circuit-break (`fix(agent): circuit-break crashed hooks`).
  - New `HookLoopBus` exposes `todo-gate`, `premature-stop`,
    `tool-intent`, and `dead-loop` built-in hooks via the
    `[steering]` / `[hooks]` config surface; runtime-context channel
    keeps injections off the durable transcript.
  - Settings UI (`HooksSection`) gains event/match editor;
    `duya hook add --yes` now actually persists
    (`fix(cli): forward hook --yes`).

- **CLI maturity**
  - `duya memory search / rebuild` search and rebuild invocations;
    `scan_paths` honored at rebuild time
    (`fix(cli): forward hook --yes, add memory search/rebuild,
    honor scan_paths`).
  - `agent-create --allow/--deny/--plugins` made repeatable; in-process
    runner's `process.exit` guarded against the agent process;
    config-clear flag propagated through the control-plane runner.

- **Agent profile / permission live switching**
  - Profiles and permissions switch mid-session without restart; prompts
    and skills sections re-resolve against the active profile.
  - Plan-task mode toggle lifted to session level with persistence.

- **Image generation**
  - New `image_generation` tool and richer tool-row metadata (icons,
    counts, token-usage tag in the stream header).

- **Stage1 policy incremental edits**
  - Stage 1 curation policy edits are now anchored to numbered rules
    (`S1–S9`) with an `edits[]` upsert/remove protocol that prevents
    whole-file rewrites.

- **Usage dashboard rewrite**
  - Header ring now folds in cost totals with currency-aware formatting;
    cross-cutting fixes for stale cache hits and mis-attributed cache
    reads.

- **Subagent transcript unification**
  - Subagent transcripts under `~/.duya/...` resolve to a single roll-out
    per session; orphaned non-UUID `rollout_id`s are reconciled by the
    catalog sync.

**Pre-release verification**

- `npm run typecheck:all` — 0 errors (web / agent / cli / conductor).
- `npm run electron:pack:win` — local pack (this run).
