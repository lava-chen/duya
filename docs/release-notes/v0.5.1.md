**v0.5.1** (2026-07-31) — patch release on the `0.5.x` line.

Plugin system cleanup and automation UI rewrite. Removes unused plugin
lifecycle modules and consolidates the plugin IPC surface; ships seven
new built-in plugins and rewrites the Automation view.

**Highlights**

- **Plugin system cleanup (BREAKING)**
  - Removes `installed-plugins-manager`, `auto-updater`, and the
    `agents/process-pool` shim — plugin install/update is now owned by
    the registry store and the bundled-plugin loader.
  - Drops unused type modules `plugin-error-types` and
    `plugin-security-types`; `plugin-handlers.ts` IPC surface trimmed
    by ~150 lines.
  - `MarketplaceConnectors.tsx` removed; marketplace no longer hosts
    third-party app connectors.
  - Scope manager simplified (−68 lines); PluginRegistryStore now owns
    enable/disable state directly.

- **Seven new built-in plugins**
  - `design-suite`, `figma-design`, `linear-project-execution`,
    `notion-knowledge`, `sentry-debugging`, `supabase-development`,
    `vercel-deployment` — each ships an `apps/` manifest entry.

- **Automation UI rewrite**
  - `AutomationView.tsx` rewritten (−1667 lines) with shared Duya
    components, restored run-history section, and fixed
    more-menu outside-click handling.
  - `MCPSettingsDialog` added with i18n (zh/en) for the MCP server
    JSON editor.

- **Memory state polish**
  - `compactMessages`, `prompt`, `wakeup`, `eligibility`, `lease`,
    and `projectionContent` tightened to reduce allocation churn and
    double-consolidation races.
  - E2E scripts renamed `memory-v2-e2e.sh` → `memory-e2e.sh` and
    `reconcile-memory-v2-projections.mjs` →
    `reconcile-memory-projections.mjs` (v2 suffix dropped).

**Breaking changes**

- Plugin IPC handlers removed: install/update lifecycle endpoints no
  longer exist; clients must use the registry store API.
- `plugin-error-types` and `plugin-security-types` barrels removed
  from `src/lib/`.
- `MarketplaceConnectors.tsx` removed from the extensions page.

**Pre-release verification**

- `npm run typecheck:all` — 0 errors (web / agent / cli / conductor).
- `npm run electron:build` — succeeded; agent bundle 7.92 MB.
- `npm run electron:pack:win` — `DUYA.Setup.0.5.1.exe` 162.97 MB.
- afterPack verified `agent-process-entry.js`, `BashWorker.js`, and
  `better_sqlite3.node` in `release/win-unpacked/resources/`.
